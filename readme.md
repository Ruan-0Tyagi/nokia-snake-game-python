# 🐍 Nokia Snake Game in Python

A recreation of the classic Nokia Snake Game using Python Turtle Graphics.

## Features

- Classic Nokia Snake gameplay.
- Random food generation.
- Snake grows after eating food.
- Live score tracking.
- Wall and self-collision detection.

## Tech Stack

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)
- Random Module

## Run the Game

```bash
python snake_game.py
```
